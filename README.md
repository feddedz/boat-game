# TURBO TIDE

An arcade speedboat racer in the spirit of early-2000s arcade cabinets. It runs entirely in the browser:
plain HTML + JavaScript, no build step, no dependencies, no asset files (graphics and sound are generated at runtime).

## Play

Open `index.html`, or host the repo on GitHub Pages:
**Settings → Pages → Deploy from a branch →** pick the branch and `/ (root)`.

| Action | Keyboard | Touch |
| --- | --- | --- |
| Steer | ← → or A D | ◀ ▶ buttons |
| Throttle | ↑ or W | automatic |
| Brake | ↓ or S | BRAKE |
| Turbo | Space or Shift | BOOST |
| Start / confirm | Enter | tap |
| Pause / mute | P / M | |

## How it works

- 3 courses (Coral Cove, Canyon Fury, Neon Harbor), 3 laps each, 7 rival boats.
- Beat the clock: every checkpoint adds time. Run out and it's game over.
- Grab blue canisters to fill the turbo meter, hit ramps for big air, dodge logs, mines and barrels.
- Best times are saved in your browser.
